# **Notes App (Angular)**

![Notes App Screenshot](https://res.cloudinary.com/ddo3iuibt/image/upload/v1744386748/trdypaxl5t45hiaxzs6s.png)

## _Description_

Aplicación para crear, editar y marcar notas como completadas. Desarrollada con Angular como ejercicio práctico para explorar las nuevas características del framework.

## _Technologies_

- Angular
- Typescript
- HTML
- CSS

## _Features_

- Agregar nuevas notas
- Marcar notas como completadas
- Editar notas existentes
- (Opcional) Guardar usando una API externa
